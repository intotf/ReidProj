# reIdMp4-cli 视频人物识别工具

## 核心原则

**用户必须提供完整的 MP4 视频绝对路径，或包含 MP4 文件的目录绝对路径。** 分组 ID 为必填参数，默认为 `group2`。如果用户未提供视频路径/目录路径，必须明确询问。

## 重要变更说明

- 分组 ID **实际为必填参数**（工具用法要求），用户未指定时使用默认值 `group2`
- 支持传入**目录路径**批量处理目录下所有 MP4 文件，自动逐个执行识别

## 工作流程

### 第一步：获取必要参数

必须从用户处获取以下参数：

1. **MP4 视频路径或目录路径** — 可以是单个文件的绝对路径（如 `D:\videos\clip.mp4`），也可以是包含 MP4 文件的目录绝对路径（如 `D:\videos\`）
2. **分组 ID**（可选，默认 `group2`） — 服务端预定义的人物分组标识（如 `family01`、`group2`）

如果用户未提供路径，按以下方式询问：

> 请提供 MP4 视频文件的绝对路径，或包含 MP4 视频的目录绝对路径

如果用户未提供分组 ID，直接使用默认值 `group2`，无需询问。

**禁止在用户未提供路径时自行假设或使用占位路径执行命令。**

### 第二步：判断路径类型并获取视频列表

**情况 A — 用户提供的是单个 MP4 文件路径：**
- 直接使用该路径，无需扫描目录

**情况 B — 用户提供的是目录路径：**
- 扫描该目录下所有 `.mp4` 文件
- 如果没有 MP4 文件，告知用户该目录下未找到 MP4 视频，不要执行识别
- 如果找到 MP4 文件，记录到视频列表中

### 第三步：执行识别

对每一个 MP4 视频文件，依次执行命令：

```bash
G:\Tools\ReIdMp4Cli\ReIdMp4Cli "<MP4视频绝对路径>" "<分组ID>"
```

**可选参数（按需追加到命令末尾）：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--server-url` | `http://localhost:9000` | ReidFeature 服务地址 |
| `--threshold` | `0.9` | 相似度阈值 |
| `--flags` | `0` | 检测标志: 0=All, 1=SkipFaceDetection, 2=StopOnFirstFrameHit |
| `--ffmpeg-path` | 自动从 PATH 查找 | ffmpeg 可执行文件路径 |
| `--save-matched` | — | 匹配时保存抽帧图片到 `{MP4文件名}_temp` 目录 |

**关于 `--save-matched` 的使用说明：**
- 默认**不开启**，即不保存匹配帧图片
- 如果用户希望保存匹配到的帧图片，在执行前主动询问用户是否开启保存功能
- 开启后，匹配帧会保存到视频所在目录下的 `{MP4文件名}_temp` 文件夹中

完整示例：

```bash
# 单个文件（不保存匹配帧）
G:\Tools\ReIdMp4Cli\ReIdMp4Cli "D:\videos\clip.mp4" "group2"

# 单个文件（保存匹配帧）
G:\Tools\ReIdMp4Cli\ReIdMp4Cli "D:\videos\clip.mp4" "group2" --save-matched

# 自定义参数
G:\Tools\ReIdMp4Cli "D:\videos\clip.mp4" "family01" --server-url http://192.168.1.100:5000 --threshold 0.85 --flags 1
```

### 第四步：输出结果

**每个视频单独输出结果表格，格式如下：**

#### 逐帧匹配详情表格

| 帧位置 | 人物 | 目标图片 | 相似度 | 面部相似度 |
|--------|------|--------|--------|-----------|
| frame_0002.jpg | laiguowei | 12_0004.jpg | 0.9781 | 0.6888 |

#### 汇总信息

- 总帧数 / 匹配帧数 / 匹配率
- 🏆 最高相似度匹配详情（帧、人物、目标图片、相似度、面部相似度）
- **（如开启 `--save-matched`）** 匹配帧保存路径展示

#### 保存路径展示格式

如果执行时使用了 `--save-matched`，在汇总信息中增加一行：

```
匹配帧保存: G:\ReIdTest\videos\D20260727T084931Z04090D03050C0900_M11_temp
```

保存目录规则：视频文件所在目录 `\` 视频文件名（不含扩展名）`_temp`

## 参数说明

- **MP4 视频路径** — 支持单个 MP4 文件绝对路径，或包含 MP4 文件的目录绝对路径
- **分组 ID**（默认 `group2`） — 对应 ReidFeature 服务端 `PersonGroupProvider` 中注册的分组名称

## 输出说明

工具每帧会输出以下信息：

- `人物` — 匹配到的人物名称
- `ID`（目标图片） — 匹配到的人物对应的**目标图片文件名**
- `相似度` — 整体特征相似度（主要匹配指标，≥阈值判定为匹配）
- `面部相似度` — 面部特征相似度（辅助参考）
- `来源图片` — 有时显示为来源图片文件名

汇总输出：
- 总帧数、匹配帧数、匹配率
- 最高相似度匹配详情（帧、人物、目标图片、相似度、面部相似度）

程序退出码说明：
- `0` — 匹配到人物
- `1` — 参数错误或无匹配

## 行为规则

1. **路径必须由用户提供** — 支持单个文件或目录路径；分组 ID 未指定时使用默认值 `group2`
2. 自动通过 ffmpeg 按 **1 帧/秒** 的频率抽帧
3. 每帧发送到 ReidFeature 服务的 `/recognize/image/{groupId}` 接口进行识别
4. 服务端返回的每个匹配结果均会展示（可能一帧匹配多个人物）
5. 临时帧文件在程序结束后自动清理（未匹配的帧不会保留）
6. **目录批量处理**：如果用户传入目录路径，自动扫描所有 MP4 文件并逐个识别
7. 如果执行失败，向用户反馈错误信息，确认路径和服务地址是否正确

## `--save-matched` 参数相关规则

1. 默认**不保存**匹配帧，仅在用户明确同意或主动要求时使用 `--save-matched`
2. 用户表达如"保存匹配的图片"、"把识别到的帧存下来"、"截图保存"等意愿时，视为需要开启
3. 开启后，保存路径为：视频所在目录 `\` 视频文件名（不含扩展名）`_temp`
4. 结果展示时需明确显示匹配帧保存路径，格式为：`匹配帧保存: <保存目录绝对路径>`
5. 目录批量处理时，每个视频的 `--save-matched` 独立生效，各自保存到各自的 `_temp` 目录
