# ReidFeature 权重 / 阈值对比测试总报告

日期：2026-08-07　数据源：生产 V4（端口 9000）实测

## 一、测试环境

- 服务：ReidFeature 生产版，多成员混合判定
  - 判定逻辑：`best > 0.88 && (与次高分差 > 0.08 || best >= 兜底阈值)`
  - 兜底阈值支持查询参数 `highConfidenceThreshold` 动态调整（默认 0.965）
- 生产库：多成员，赖国伟 × 3 条（赖国伟 / 赖国伟-正面 / 赖国伟-背面）
- 测试集：18 个视频（10 个成员 + 8 个陌生人 D*），H264 裸流，抽帧间隔 0.5s
- 成员视频：P-D20260804/06 共 6 个、PN-D 3 个、E-D 1 个；陌生人：D20260804~06 共 8 个

## 四、30/30/30/10 各阈值明细

兜底 0.965：仅 E-D（0.8886，靠 margin）命中，其余 9 个成员全漏（0.82~0.88），陌生人 0 误报。

兜底 0.88 / 0.86 / 0.84 / 0.82 四档**结果完全相同**：
- 命中：E-D（0.8886）、P-D20260804T080556（0.8836）、P-D20260806T063546（0.8803）
- 误报：D20260805T002401（0.8837）、D20260805T011850（0.8818）
- 其余 7 个成员（0.816~0.855）全漏

## 五、关键发现

1. **体型 + 步态是负资产**：30/30/30/10 把本人分数压到 0.82~0.89、与陌生人 0.79~0.88 几乎完全重叠；
   去掉它们（45/55）后本人升到 0.965~0.979，分离度大幅改善。
2. **兜底阈值只对 ≥0.88 的分数起作用**（基础 HitThreshold=0.88）：30/30/30/10 下 0.82~0.88 的本人
   只能靠 margin>0.08 命中，而这些视频 margin 均 <0.08 → 调兜底救不回来；把兜底降到 0.82~0.88
   只会多放行 2 个陌生人（0.8818/0.8837），这就是四档结果完全相同的原因。
3. **阈值窗口窄**：45/55 下最接近的陌生人 0.9615、最低命中成员 0.9651，可用窗口约 0.004；
   分数抖动 0.01 就可能翻盘。
4. **模型区分度不足（根本）**：本人与陌生人特征高度重叠（跨人余弦 0.84~0.96），
   E-D/两个 PN-D2026 漏检的视频分数（0.959~0.960）低于最接近的陌生人（0.9615），
   任何单一阈值都无法"全命中+全拒"。
5. **短出镜 + 头被截是边界样本**：漏检的两个 PN-D2026 视频人物只在前 3~4 秒出现、
   全程背身越走越小、检测框截掉头部；即使最好的帧也只有 0.958，融合已高于任何单帧。
6. **头部门控无效**：MoveNet 鼻尖在头截背身裁剪图上误报（conf 0.44），门控零效果，已回滚。
7. **多成员 + append 方案有效**：同一成员多视频各自成条 + 高分兜底，解决了"同一人多条目歧义误拒"。

## 六、结论与建议

### 推荐最终配置
- **权重：wCloth=0.45, wHead=0.55, wBody=0, wGait=0**
- **兜底阈值：0.965**（零误报优先；如需多放行成员可降到 0.959~0.960，但会引入 1~2 个陌生人误报）
- **注册：append=true 多条目**（每段视频独立成条，用固定注册源视频）

### 后续改进方向（按优先级）
1. **治本**：接入人脸识别（models 已有 scrfd/glintr100/w600k）或换/微调更适合门铃场景的 ReID 模型，
   这是解决"本人与陌生人分不开"的唯一根本出路。
2. **采集质量**：让人物正面、头部清晰、出镜更久，减少"短出镜+头截"边界样本。
3. **阈值参数化已完成**：识别请求可直接传 `highConfidenceThreshold`，按场景/库动态调整。
4. 固定注册源视频（`laiguowei\目标` 下两个视频），保证库项特征一致。
