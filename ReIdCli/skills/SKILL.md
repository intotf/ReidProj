# ReID CLI 视频找人工具

在视频中搜索指定的目标人物。输入目标照片和视频目录，输出匹配到的帧位置和相似度。

## 调用方式

```bash
G:\reidCli\ReIdCli.exe "<目标图片>" "<视频目录>"
```

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| 参数1 | 是 | 目标人物图片的绝对路径，多张用英文逗号分隔 |
| 参数2 | 是 | 视频文件所在目录的绝对路径 |

## 调用示例

```bash
# 搜索单个人物
G:\reidCli\ReIdCli.exe "D:\photos\henry.jpg" "D:\videos\2026-07"

# 搜索多个人物
G:\reidCli\ReIdCli.exe "D:\photos\henry.jpg,D:\photos\alice.jpg" "D:\videos\today"
```

## 输出说明

匹配成功时输出表格：

```
目标             视频                       帧位置               相似度
────────────────────────────────────────────────────────────────────────────────
henry           doorbell_2026-07-24.mp4    frame_0032.jpg       0.9512
────────────────────────────────────────────────────────────────────────────────
总计: 1 个匹配
```

未找到匹配时输出：`未找到任何匹配结果。`

## 行为规则

- 相似度达到 0.93 即判定匹配，并停止该视频的后续搜索
- 每张目标图片取画面中置信度最高的人作为搜索目标
- 支持的视频格式：mp4, avi, mkv, mov, flv, wmv, webm, ts
- 程序退出码：0 表示正常完成，1 表示参数错误或无有效目标
