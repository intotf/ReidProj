# ReID CLI 视频找人工具

在视频中搜索指定的目标人物。输入目标照片和视频目录，输出匹配到的帧位置和相似度。

## 核心原则

**必须由用户提供完整的绝对路径，不要猜测或使用默认路径。** 如果用户未提供目标人物图片路径或视频文件目录路径中的任何一个，必须明确询问缺少的路径信息。

## 工作流程

### 第一步：获取必要参数

必须从用户处获取以下两个参数（均为绝对路径）：

1. **目标人物图片路径**：目标人物照片的绝对路径（如 `D:\photos\henry.jpg`），多张用英文逗号分隔
2. **视频文件目录路径**：视频文件所在目录的绝对路径（如 `D:\videos\2026-07`）

如果用户缺少任一参数，按以下方式询问：

> 请提供以下信息：
> 1. 目标人物图片的绝对路径（多张用英文逗号分隔）
> 2. 视频文件所在目录的绝对路径

**禁止在用户未提供路径时自行假设或使用占位路径执行命令。**

### 第二步：执行搜索

**判断目标图片参数类型：**

- **如果是文件路径**（如 `D:\photos\henry.jpg` 或逗号分隔的多个文件路径）：直接作为参数执行。
- **如果是目录路径**（如 `D:\photos\targets\`）：先扫描该目录下所有图片文件（支持 jpg、jpeg、png），将扫描到的所有图片绝对路径用英文逗号拼接后作为参数执行。

扫描目录示例（Windows CMD）：

```cmd
dir /b /a-d "D:\photos\targets\*.jpg" "D:\photos\targets\*.jpeg" "D:\photos\targets\*.png"
```

如果目录下没有任何图片文件，告知用户该目录下未找到图片，不要执行搜索。

两个路径都准备好后，执行命令：

```bash
G:\reidCli\ReIdCli.exe "<目标图片绝对路径，逗号分隔>" "<视频目录绝对路径>"
```

### 第三步：返回结果

根据程序输出向用户展示搜索结果。

## 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| 参数1 | 是 | 目标人物图片的绝对路径，多张用英文逗号分隔 |
| 参数2 | 是 | 视频文件所在目录的绝对路径 |

## 调用示例

```bash
# 搜索单个人物
G:\reidCli\ReIdCli.exe "D:\photos\henry.jpg" "D:\videos\2026-07"

# 搜索多个人物
G:\reidCli\ReIdCli.exe "D:\photos\henry.jpg,D:\photos\alice.jpg" "D:\videos\today"
```

## 输出说明

匹配成功时输出表格：

```
目标             视频                       帧位置               相似度
────────────────────────────────────────────────────────────────────────────────
henry           doorbell_2026-07-24.mp4    frame_0032.jpg       0.9512
────────────────────────────────────────────────────────────────────────────────
总计: 1 个匹配
```

未找到匹配时输出：`未找到任何匹配结果。`

## 行为规则

1. **路径必须由用户提供**：不要猜测、不要使用默认值、不要用相对路径，两个参数都必须是用户明确告知的绝对路径
2. 相似度达到 0.93 即判定匹配，并停止该视频的后续搜索
3. 每张目标图片取画面中置信度最高的人作为搜索目标
4. 支持的视频格式：mp4、avi、mkv、mov、flv、wmv、webm、ts
5. 程序退出码：0 表示正常完成，1 表示参数错误或无有效目标
6. 如果执行失败，向用户反馈错误信息，确认路径是否正确
